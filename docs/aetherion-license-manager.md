# Aetherion License Manager

Actualizado el 9 de octubre de 2026. La sección de Aetherion incorpora License Manager: gestión de cuentas, edición de planes existentes, renovación, suspensión y presencia basada en contacto autenticado reciente. El panel conserva la duración que se edita durante sus actualizaciones de conexión cada treinta segundos. Online corresponde a una ventana de seis minutos; Offline puede incluir clientes usando su pase local.

Se agregaron tres imágenes a la galería, que ahora contiene 18 vistas. Son capturas de los controles reales de Windows Forms con cuentas ficticias: listado, plan personalizado de 45 días y emisión vacía. No incluyen credenciales, claves, direcciones del servicio, IDs de equipos reales ni datos de clientes. La generación no leyó configuración privada y bloqueó red y cambios de cuentas.

Texto y controles disponibles en español e inglés. Verificados carga de las tres imágenes, navegación entre ellas, Escape, restauración de foco y ausencia de desbordamiento horizontal en escritorio de 1280 px y móvil de 390 px. Sin errores en consola. JavaScript y git diff --check correctos.

30 pruebas pasan en el proyecto de licencias; el instalador Windows 1.1.0 se generó correctamente. El VPS de licencias no se actualizó por falta de conexión administrativa. Estos cambios del portfolio están en el árbol local y no representan un despliegue público confirmado.
